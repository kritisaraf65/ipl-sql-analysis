# IPL SQL Analysis

## 📌 Project Overview
This project analyzes IPL match and ball-by-ball data using PostgreSQL to uncover team performance, player performance, match outcomes, and batting/bowling trends.

## 🛠️ Tools & Technologies
- PostgreSQL
- SQL
- pgAdmin 4

## 📊 Dataset
The project uses IPL match-level and ball-by-ball delivery data.

## 🔍 Analysis Performed
- Data exploration and basic analysis
- Team performance analysis
- Player performance analysis
- Batting and bowling trends
- Match and toss analysis
- Advanced SQL analysis using JOINs, subqueries, UNION, aggregate functions, and other SQL techniques

## 💡 Key Insights

- Identified team-wise performance and win patterns across IPL seasons.
- Analyzed batting performance, including top run-scorers and boundary-hitting trends.
- Analyzed bowling performance and identified leading wicket-takers.
- Examined toss decisions and their relationship with match outcomes.
- Compared team scoring patterns, match totals, and venue-wise trends.

## 📁 Project Files
- `IPL_Match_Analysis.sql` — Contains table creation, data exploration, and 20 SQL analysis queries.
- `README.md` — Project documentation.
